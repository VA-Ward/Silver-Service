I haven't got an access key
  1. Sign in to GitHub and go to Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Generate new token. Name it "Website editor".
  3. Under Repository access, choose Only select repositories and pick your website's repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave the rest alone.
  5. Generate it, copy the key, paste it above. Keep a copy safe — GitHub shows it once.
